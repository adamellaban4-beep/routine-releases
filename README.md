# روتيني — ملفات التحديث

الريبو ده فيه **ملفات APK بس**. الكود مش هنا.

كل تحديث بيتنشر هنا كـ**Release**، واسم الـRelease هو رقم `versionCode` بتاع النسخة.

التطبيق نفسه بيشوف آخر Release هنا أول ما يفتح، ولو فيه رقم أعلى من النسخة اللي عندك بيقولك "فيه تحديث جديد".

## تنزّل بإيدك

افتح [آخر إصدار](../../releases/latest) ونزّل ملف الـAPK.

> كل الملفات هنا موقّعة بنفس مفتاح التوقيع، فبتتسطّب فوق النسخة اللي على موبايلك من غير ما بياناتك تتمسح. **متمسحش التطبيق القديم قبل ما تسطّب** — لو مسحته بياناتك بتروح معاه.
